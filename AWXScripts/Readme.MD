Описание файлов каталога

AppInstall.yml - плэйбук для установки приложений

CreateUser.yml - плэйбук для создания пользователя

InstallAnydesk.yml - плэйбук для установки Anydesk

InstallandPreconfigWireguard.yml - плэйбук для установки и начальной конфигурации Wireguard

RemminaProtection.yml - плэйбук для установки пароля на внесение изменений в настройки Remmina (осуществляется подкидыванием файла настроек)

SomethingToDesktop.yml - плэйбук для копирования на рабочий стол неудаляемых ярлыков

VPNandVPN-Reserv.yml - плэйбук для создания на компьютере пользователя подключений по VPN 

prod-AddConnectionInRemmina.yml - плэйбук для создания на компьютере пользователя в программе Remmina подключения к удаленному серверу 

prod-AnydeskConfPart.txt - шаблон настроек Anydesk, который нужно подкинуть на компьютер пользователю в /etc/anydesk/system.conf

prod-ConfigL2TPnotebook.yml - плэйбук для полной настройки компьютера пользователя для работы по L2TP

prod-ConfigWGnotebook.yml - плэйбук для полной настройки компьютера пользователя для работы по Wireguard

prod-Corp-VPN-Reserv.nmconnection и prod-Corp-VPN.nmconnection - файлы для создания на компьютере пользователя VPN-подключения в NetworkManager

prod-NBPreconfig4AWX.sh - скрипт для первоначальной настройки компьютера пользователя для рабоы с ansible 

prod-RemoteNBFallover.sh - скрипт автоматического переключения VPN на компьютере пользователя с основного на резервный

prod-anydesk_6.4.0-1_amd64.deb - пакет для установки Anydesk

prod-org.remmina.Remmina.desktop - файл-ярлык для Remmina

prod-remmina.pref - шаблон настроек Remmina, который нужно подкинуть на компьютер пользователю в /home/user/.config/remmina/remmina.pref

prod-wg0.conf - шаблон для конфигурарования Wireguard на компьютере пользователя
