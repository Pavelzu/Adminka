Каталог с плэйбуками для управления настройками устройства вендора Mikrotik



prod-CreateNewPeer.yml - создание нового пира Wireguard

prod-DisablePeer.yml - отключение пира Wireguard по имени

prod-EnablePeer.yml - включение пира Wireguard по имени

prod-GetPeersList.yml - выгрузка в постоянную память устройства актуального списка пиров Wireguard

prod-RemovePeerByName.yml - удаление пира Wireguard по имени
